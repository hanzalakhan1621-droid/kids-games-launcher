HOW TO HOST WITH GITHUB PAGES
1. Create a new GitHub repository, for example: kids-games-launcher
2. Upload all five files from this folder to the repository root.
3. Open the repository Settings.
4. Open Pages.
5. Under "Build and deployment", choose:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
6. Save.
7. GitHub will give you an HTTPS address such as:
   https://YOURNAME.github.io/kids-games-launcher/

HOW TO INSTALL ON CHROMEOS FLEX
1. Open that HTTPS address in Chrome.
2. Open the Chrome menu.
3. Choose Install Kids Games / Install app.
   If Chrome instead shows "Create shortcut", create it and then pin it to the Shelf.
4. The launcher can then open in its own app-style window.

IMPORTANT
- The launcher shell can load offline after first use, but the actual games require internet.
- The Parent PIN is only a simple deterrent because this is a browser app.
- For stronger child protection, also use Family Link / website restrictions.
- Keep the direct game list curated by a parent.
